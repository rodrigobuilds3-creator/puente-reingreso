# PUENTE

PUENTE is Team 6's Week 4 Business Bending prototype: a mobile-first re-entry navigator for a 20-year-old informal candy seller in Ecatepec who needs to protect household cash while considering formal work.

The prototype calculates a 7- or 14-day protected floor, makes transition and opportunity costs visible, presents two equal-weight routes without scoring, and preserves candy sales as a temporary bridge to the first paycheck.

## Local validation

```bash
npm install
npm test
npm run build
npm run dev
```

All data is invented. Nothing is persisted or transmitted, and the AI-style explanation is explicitly simulated.
